## 1부. 데이터 구하기 — 국가교통정보센터 공개 CCTV

전국 고속도로·국도의 CCTV 실시간 영상을 **무료 공개 API**로 제공합니다. (공개용이므로 합법적 사용 가능)

### API 키 발급 (5분, 무료)

1. **ITS 국가교통정보센터 OpenAPI** (https://www.its.go.kr → 오픈API) 접속 → 회원가입 → **인증키 신청** (즉시 발급)
2. "CCTV 정보" API 활용 신청

### CCTV 목록 받기

발급받은 키로 원하는 지역(경도/위도 범위)의 CCTV 목록과 **영상 주소(HLS)**를 받습니다:

```python
import requests

API_KEY = "발급받은키"
# minX/maxX(경도), minY/maxY(위도)를 우리 동네 좌표로 (구글지도에서 확인)
url = (f"https://openapi.its.go.kr:9443/cctvInfo?"
       f"apiKey={API_KEY}&type=its&cctvType=1"
       f"&minX=126.8&maxX=127.2&minY=37.4&maxY=37.7&getType=json")

data = requests.get(url).json()
for cctv in data['response']['data'][:5]:
    print(cctv['cctvname'], cctv['cctvurl'])   # cctvurl = 영상 스트림 주소
```

> 💡 파라미터 이름·형식은 ITS OpenAPI 문서 기준입니다. 신청 후 받은 최신 문서의 예제를 꼭 확인하세요.
> `cctvurl`로 받은 주소는 브라우저(VLC)에서 먼저 열어보고 잘 나오는 CCTV를 고르세요.

## 2부. 모델 선택 — jetson-inference vs YOLO

| | **jetson-inference (SSD-Mobilenet-v2)** ✅ 기본 | **YOLO** (심화) |
|---|---|---|
| 설치 | NVIDIA 공식, 아래 몇 줄이면 끝 | 버전 맞추기 까다로움 |
| 속도(4GB) | TensorRT 최적화 ~20 FPS | v4-tiny ~15, v5n은 변환 없인 5 이하 |
| 차량 클래스 | COCO 사전학습(car/bus/truck) — **훈련 불필요** | 동일 |
| 수업 추천 | **전원 이걸로 시작** | 심화 학생만 |

> ⚠️ YOLO의 함정: JetPack 4.6 기본 파이썬은 3.6인데 최신 YOLO(v5/v8)는 **3.8+**를 요구합니다.
> 심화로 가려면 ① YOLOv4-tiny(darknet, 파이썬 제약 없음) 또는
> ② [02_python_jupyter](../02_python_jupyter/python_jupyter_venv.md)에서 만든 **파이썬 3.8 venv** 위에 YOLOv5n — 두 경로가 현실적입니다.

### jetson-inference 설치 (기본 경로)

```bash
sudo apt-get update
sudo apt-get install -y git cmake libpython3-dev python3-numpy
git clone --recursive --depth=1 https://github.com/dusty-nv/jetson-inference
cd jetson-inference && mkdir build && cd build
cmake ../          # 모델 선택 화면에서 SSD-Mobilenet-v2 포함(기본값) 그대로 OK
make -j$(nproc)
sudo make install && sudo ldconfig
```

설치 확인 — 웹캠으로 바로 테스트:

```bash
detectnet.py /dev/video0     # 사물에 박스가 그려지면 성공!
```

## 3부. 교통량 카운터 시작 코드

```python
# traffic_counter.py — CCTV에서 차량 수를 세어 CSV로 기록
import cv2, time, csv
from datetime import datetime
from jetson_inference import detectNet
from jetson_utils import cudaFromNumpy

CCTV_URL = "1부에서 고른 cctvurl 주소"
VEHICLE = {'car', 'bus', 'truck', 'motorcycle'}

net = detectNet("ssd-mobilenet-v2", threshold=0.5)
cap = cv2.VideoCapture(CCTV_URL)          # CCTV 스트림 열기 (웹캠 테스트: 0)

with open('traffic_log.csv', 'a', newline='') as f:
    writer = csv.writer(f)
    while True:
        ret, frame = cap.read()
        if not ret:                        # 스트림 끊기면 다시 연결
            cap = cv2.VideoCapture(CCTV_URL); time.sleep(3); continue

        img = cudaFromNumpy(cv2.cvtColor(frame, cv2.COLOR_BGR2RGBA))
        detections = net.Detect(img)
        count = sum(1 for d in detections
                    if net.GetClassDesc(d.ClassID) in VEHICLE)

        now = datetime.now().strftime('%Y-%m-%d %H:%M:%S')
        writer.writerow([now, count]); f.flush()
        print(now, "차량:", count)
        time.sleep(60)                     # 1분에 한 번 기록 (원하는 주기로)
```

> 💡 처음에는 `CCTV_URL` 대신 `0`(웹캠)으로 미니카·장난감 차를 놓고 테스트하면 디버깅이 쉽습니다.
> 💡 같은 차가 여러 번 세어지는 문제(중복 카운트)는 "1분에 한 장씩 순간 대수를 기록"하는 방식으로 단순화했습니다 — 초보 프로젝트에선 이걸로 충분하고, 심화로 객체 추적(tracking)에 도전해볼 수 있습니다.

## 4부. 데이터 분석 & 시각화

하루 이상 돌린 `traffic_log.csv`를 [06_data_analysis](../06_data_analysis) 스타일로 분석합니다:

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv('traffic_log.csv', names=['time', 'count'], parse_dates=['time'])
hourly = df.groupby(df['time'].dt.hour)['count'].mean()

hourly.plot(kind='bar', title='시간대별 평균 교통량')
plt.xlabel('시(hour)'); plt.ylabel('평균 차량 수')
plt.savefig('traffic_by_hour.png')
```
