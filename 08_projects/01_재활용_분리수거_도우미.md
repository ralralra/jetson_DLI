# ♻️ 프로젝트 1. 재활용 분리수거 도우미

> **쓰레기를 카메라에 비추면 "페트병이에요! 라벨 떼서 버리세요"라고 분류해주는 AI**
> 기간: 1~2주 · 난이도: 🟢 쉬움 · 대상: DLI 수료 직후 첫 프로젝트

## 왜 이 프로젝트인가?

DLI 과정에서 한 **Thumbs Project(👍/👎 분류)와 구조가 100% 같습니다.**
클래스 이름만 `thumbs_up/thumbs_down` → `캔/페트/종이/일반`으로 바꾸면 되므로,
배운 것을 "내 것"으로 만드는 데 가장 좋은 첫 프로젝트입니다.

## 준비물

- 젯슨나노 (2GB/4GB) + USB 카메라 — DLI 실습 환경 그대로
- 분류할 실물 쓰레기 샘플: 캔, 페트병, 종이(우유갑), 일반쓰레기 각 3~5개씩
- DLI 도커 컨테이너 (`./docker_dli_run.sh` — [3_docker_and_swap.md](../01_jetson_dli_course/3_docker_and_swap.md))

## 진행 단계

### 1단계. 클래스 설계 (30분)

- 처음엔 **2개 클래스**로 시작하세요 (예: `can` vs `pet`). 잘 되면 4개로 확장.
- 클래스가 늘수록 데이터도 늘어야 합니다: 클래스당 **최소 30장, 권장 50장+**

### 2단계. 노트북 복사 & 수정 (1시간)

1. JupyterLab에서 `classification/classification_interactive.ipynb`를 **복사**해서 `recycle_project.ipynb`로 이름 변경
2. 코드에서 TASK와 CATEGORIES를 수정:

```python
TASK = 'recycle'
CATEGORIES = ['can', 'pet', 'paper', 'general']   # 처음엔 ['can','pet'] 2개로!
```

> 💡 DLI 퀴즈에서 배웠죠? **카테고리를 추가하면 출력 차수가 1씩 증가** — 코드가 CATEGORIES 길이로 자동 처리해줍니다.

### 3단계. 데이터 수집 (1~2시간) — 품질이 성패를 가릅니다!

DLI에서 배운 데이터 수집 원칙 그대로:

- **다양한 배경**에서 찍기 (책상, 바닥, 손에 들고)
- **다양한 각도·거리**로 찍기 (눕혀서, 세워서, 찌그러진 캔도)
- 조명 바꿔가며 찍기
- ⚠️ 흔한 실패: 배경이 전부 같으면 AI가 "배경"을 학습해버립니다!

### 4단계. 훈련 (10~30분)

- epochs 10부터 시작 → 정확도를 보고 조절
- ⚠️ **2GB 모델**: 훈련 중 멈추면 스왑 확인(`free -h`) + 다른 프로그램 종료. 그래도 안 되면 클래스 2개·사진 30장으로 줄여서 훈련
- 4GB 모델은 4개 클래스 50장씩도 무리 없습니다

### 5단계. 라이브 데모 & 평가

- state 위젯을 `live`로 바꾸고 실물을 비춰보세요
- **평가표 만들기**: 각 클래스별 10번씩 테스트 → 정답률 기록 → 틀린 케이스는 데이터 추가 후 재훈련 (이 반복이 진짜 머신러닝 공부입니다!)

## 발표 포인트 (탐구보고서 연결)

- 데이터 몇 장부터 정확도가 안정되는가? (30장 vs 50장 vs 100장 비교 실험)
- 어떤 쓰레기가 제일 헷갈리는가? (혼동 사례 분석 — 투명 페트 vs 유리병)
- 전이학습(ResNet-18)이 왜 적은 데이터로도 되는가? (DLI 이론 복습)
