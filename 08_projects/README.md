# 🚀 젯슨나노 프로젝트 아이디어 — DLI 수료 그 다음

> DLI 수료증을 받은 학생이 **일상생활 + 공공데이터**로 할 수 있는 프로젝트 모음입니다.
> 젯슨나노 4GB 기준이며, 2GB도 ⚠️ 표시된 부분만 조심하면 가능합니다.

## 🗺️ 추천 로드맵 (이 순서대로!)

```
DLI 수료 → ① 재활용 분리수거 도우미 (1~2주, 배운 것 그대로 응용)
         → ② 교통량 카운터 (3~4주, 공공 CCTV + AI + 데이터분석 종합)
         → 발표/보고서
```

| 순서 | 프로젝트 | 왜 이 순서? |
|---|---|---|
| 1️⃣ | [재활용 분리수거 도우미](./01_재활용_분리수거_도우미.md) | DLI classification을 클래스만 바꿔 그대로 응용 — **수료 직후 첫 프로젝트로 최적** |
| 2️⃣ | [교통량 카운터](./02_교통량_카운터.md) | 공공 CCTV(국가교통정보센터) + 사물인식 + 데이터 시각화까지 **전체 파이프라인 경험** |

## 💡 그 외 아이디어 (난이도별)

**🟢 쉬움 (1~2주)**
- **미세먼지 신호등** — 에어코리아 API(공공데이터포털) 수치를 LED/OLED로 표시. 03 아두이노 + API 호출 응용. 챗봇 연동 확장 가능
- **버스 도착 알리미** — 공공데이터포털 버스도착정보 API + OLED 상시 표시

**🟡 중간 (3~4주)**
- **주차장 빈자리 알리미** — 웹캠으로 주차칸 점유 감지 (OpenCV + classification)
- **급식실 혼잡도 알리미** — 사람 수 카운트 (07 얼굴인식 출석시스템의 감지 부분 재활용)

**🔴 도전 (한 달+)**
- **이상 감지 CCTV** — 움직임 감지 시 사진 저장 + 텔레그램 알림 (모델 훈련 불필요, OpenCV 모션 감지)
- **안전모/마스크 착용 감지** — classification 응용, 산업 안전 콘셉트

## ⚠️ 수업 전 공통 준비 & 유의사항

1. **공공데이터포털(data.go.kr) 회원가입 + API 키 발급**을 첫 시간에 다 같이 해두세요 (무료, 즉시 발급)
2. **CCTV는 공개 API만 사용** — 국가교통정보센터 CCTV는 공개용이라 합법. 일반 방범용 CCTV 영상은 사용 불가!
3. **사람이 나오는 영상**은 촬영 동의 받기 + 얼굴 모자이크 습관을 함께 지도
4. 인식 모델은 **jetson-inference(SSD-Mobilenet) 우선, YOLO는 심화** — 이유는 [02_교통량_카운터.md](./02_교통량_카운터.md)의 모델 선택 절 참고
