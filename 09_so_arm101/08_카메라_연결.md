# 8️⃣ 카메라 연결 — AI의 "눈" 달아 주기

## 🎯 이 단계의 목표
- 카메라 2대의 **번호(index)** 를 찾는다.
- 원격조작을 하면서 **카메라 화면과 관절 그래프**를 함께 본다.

## 🤔 왜 카메라가 필요한가?
7단계에서는 사람이 눈으로 보고 리더암을 움직였다. AI가 혼자 움직이려면 AI에게도 **눈**이 있어야 한다.
AI는 카메라 화면을 보고 "큐브가 왼쪽에 있으니 팔을 왼쪽으로" 같은 판단을 배운다.
공식 문서에는 좋은 기준이 하나 있다. **"카메라 화면만 보고 사람이 그 작업을 할 수 있어야 한다."** 사람도 못 보는 각도라면 AI도 배울 수 없다.

| 카메라 | 추천 위치 | 역할 |
|---|---|---|
| `front` | 작업대 앞쪽 위에서 비스듬히 내려다보기 | 물체와 팔 전체 위치 파악 |
| `side` | 옆쪽 또는 그리퍼(손목) 근처 | 집는 순간의 거리·높이 파악 |

---

## 1. 카메라 연결
1. USB 카메라 2대를 PC에 꽂는다.
2. 가능하면 **서로 다른 USB 포트(다른 쪽 면)** 에 꽂는다. Juxi 위키는 **같은 USB 허브에 카메라 두 대를 꽂는 것을 권장하지 않는다.** 영상 데이터가 많아 대역폭이 부족해지기 때문이다.
3. 카메라를 집게나 거치대로 **단단히 고정**한다. 녹화 도중 카메라가 움직이면 AI가 혼란에 빠진다.

> 💡 노트북이라면 **내장 웹캠도 카메라로 잡힌다.** 보통 내장 웹캠이 0번이 된다.

---

## 2. 카메라 번호 찾기

`C:\robot\my_settings.bat` 실행 후:

```bat
lerobot-find-cameras opencv
```

📖 **이 명령은?** PC에 연결된 카메라를 모두 찾아 번호와 해상도를 출력하고, 각 카메라로 **사진을 몇 장 찍어 저장**한다.
- `opencv` : 일반 USB 카메라(웹캠)만 찾으라는 뜻이다. (OpenCV는 카메라·영상 처리용 프로그램 모음 이름이다.)

출력 예시(일부):
```
--- Detected Cameras ---
Camera #0:
  Name: OpenCV Camera @ 0
  Type: OpenCV
  Id: 0
  ...
Camera #1:
  ...
  Id: 1
```

사진은 `C:\robot\lerobot\outputs\captured_images` 폴더에 저장된다. 파일 탐색기로 열어서 **어느 번호가 어느 카메라인지** 사진으로 확인한다.

| 카메라 | 번호(Id) |
|---|---|
| front (앞/위) | ____ |
| side (옆/손목) | ____ |

찾은 번호를 `C:\robot\my_settings.bat` 의 `CAM_FRONT`, `CAM_SIDE` 에 적고 저장한 뒤, bat 파일을 **다시 실행**한다.

> ⚠️ 카메라를 다른 USB 포트로 옮기면 번호가 바뀔 수 있다. 카메라도 USB 구멍을 정해 두자.

## 3. 카메라 화면 보면서 원격조작

```bat
lerobot-teleoperate ^
    --robot.type=so101_follower ^
    --robot.port=%FOLLOWER_PORT% ^
    --robot.id=%FOLLOWER_ID% ^
    --robot.cameras="{ front: {type: opencv, index_or_path: %CAM_FRONT%, width: 640, height: 480, fps: 30}, side: {type: opencv, index_or_path: %CAM_SIDE%, width: 640, height: 480, fps: 30}}" ^
    --teleop.type=so101_leader ^
    --teleop.port=%LEADER_PORT% ^
    --teleop.id=%LEADER_ID% ^
    --display_data=true
```

📖 **이 명령은?** 7단계 원격조작에 두 가지를 더한 것이다.
- `--robot.cameras="{ ... }"` : 팔로워암에 카메라 2대를 붙인다. 중괄호 안을 풀어 읽으면 다음과 같다.

  | 항목 | 뜻 |
  |---|---|
  | `front:` / `side:` | 카메라 **이름표**. 9·11단계에서도 **똑같은 이름**을 써야 한다. |
  | `type: opencv` | 일반 USB 카메라 |
  | `index_or_path: 0` | 2번에서 찾은 카메라 번호 |
  | `width: 640, height: 480` | 해상도(가로×세로 픽셀). 작을수록 학습이 빠르다. |
  | `fps: 30` | 1초에 찍는 사진 수 |

- `--display_data=true` : **Rerun** 이라는 시각화 창을 띄워 카메라 화면과 관절 숫자 그래프를 실시간으로 보여 준다.

> 💡 bat 파일에 이미 `CAMERAS` 변수로 같은 내용을 넣어 두었다. 그래서 `--robot.cameras="%CAMERAS%"` 라고 짧게 써도 똑같이 동작한다. 9·11단계에서는 이 짧은 형태를 쓴다.

Rerun 창에서 확인할 것:
- [ ] `front`, `side` 두 카메라 화면이 모두 나온다.
- [ ] 리더암을 움직이면 관절 그래프가 따라 움직인다.
- [ ] 화면이 끊기지 않는다(뚝뚝 끊기면 아래 표 참고).

## 4. 문제가 생기면
| 증상 | 해결 |
|---|---|
| 카메라가 0개 검색됨 | 윈도우 **설정 → 개인 정보 및 보안 → 카메라** 에서 "데스크톱 앱이 카메라에 액세스하도록 허용"을 켠다 |
| 카메라 화면이 검게 나옴 / 열기 실패 | 줌·팀즈·카메라 앱 등 **카메라를 쓰는 다른 프로그램을 모두 끈다** |
| 화면이 끊기거나 fps 경고 | 해상도를 640×480으로 유지, 카메라를 다른 USB 포트로 분산 |
| 고해상도에서 느림 (고급) | 카메라 설정에 `fourcc: MJPG` 를 추가하면 압축 전송으로 대역폭이 줄어든다. 예: `{type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30, fourcc: MJPG}` |
