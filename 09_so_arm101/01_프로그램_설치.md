# 1️⃣ 프로그램 설치 — Miniforge, USB 드라이버, 그래픽카드 확인

## 🎯 이 단계의 목표
- 파이썬을 관리해 주는 **Miniforge**를 설치하고 **Miniforge Prompt** 창을 열 수 있다.
- 로봇 제어 보드를 PC가 알아보는지(**USB 드라이버**) 확인한다.
- 내 PC에 AI 학습용 **NVIDIA 그래픽카드**가 있는지 확인한다.

## 🤔 왜 이걸 먼저 해야 하나?
LeRobot은 **파이썬(Python)** 으로 만든 프로그램이다. 그런데 파이썬 프로그램은 "부품(라이브러리)"을 수십 개 가져다 쓰고, 각 부품은 버전이 맞아야 한다.
학교 PC에 이미 다른 파이썬이 깔려 있으면 버전이 엉키기 쉽다. 그래서 **Miniforge** 라는 "파이썬 관리 프로그램"을 깔고, 그 안에 LeRobot 전용 방(가상환경)을 따로 만들어 쓴다.
비유하자면, 공용 주방(PC 전체)이 아니라 **나만의 개인 주방**을 하나 차리는 것이다. 개인 주방에서는 냄비(라이브러리)를 마음대로 바꿔도 다른 사람에게 피해가 가지 않는다.

## 1. Miniforge 설치

### 1-1. 내려받기
1. 웹브라우저에서 https://conda-forge.org/download/ 에 접속한다.
2. **Windows** 항목의 `x86_64` 설치 파일(`Miniforge3-Windows-x86_64.exe`)을 내려받는다.
   - 바로 받기 링크: https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-Windows-x86_64.exe

### 1-2. 설치하기
1. 내려받은 `Miniforge3-Windows-x86_64.exe` 를 더블클릭한다.
2. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** 을 누른다.
3. 설치 화면에서 다음처럼 고른다.

| 화면 | 선택 |
|---|---|
| License Agreement | **I Agree** |
| Install for | **Just Me (recommended)** |
| 설치 위치 | 기본값 그대로 (`C:\Users\내이름\miniforge3`) |
| Advanced Options | 기본값 그대로 두고 **Install** |

> ⚠️ **윈도우 사용자 이름이 한글이거나 띄어쓰기가 있으면**(예: `C:\Users\홍길동`) 일부 프로그램이 경로를 못 읽는 문제가 생길 수 있다.
> 이 경우 설치 위치를 **`C:\miniforge3`** 처럼 영어로만 된 짧은 경로로 바꿔 주자.

### 1-3. Miniforge Prompt 열기
1. 윈도우 **시작** 버튼을 누르고 `Miniforge Prompt` 라고 입력한다.
2. 검은 창이 열리고 맨 앞에 `(base)` 라고 보이면 성공이다.

```
(base) C:\Users\내이름>
```

> 📌 **앞으로 "명령을 입력한다"는 말은 모두 이 Miniforge Prompt 창에서 입력한다는 뜻이다.**
> 일반 "명령 프롬프트"나 "PowerShell"을 열면 `conda` 명령을 못 찾는다는 오류가 날 수 있다.

### 1-4. 설치 확인

```bat
conda --version
```

📖 **이 명령은?** conda(Miniforge 안에 들어 있는 관리 프로그램)의 버전을 보여 준다. `conda 25.x.x` 처럼 숫자가 나오면 설치가 잘 된 것이다.

## 2. 작업 폴더 만들기

LeRobot 코드를 넣어 둘 폴더를 만든다. **한글·띄어쓰기가 없는 짧은 경로**가 안전하다.

```bat
mkdir C:\robot
cd /d C:\robot
```

📖 **이 명령은?**
- `mkdir C:\robot` : C 드라이브에 `robot` 이라는 새 폴더를 만든다 (make directory).
- `cd /d C:\robot` : 그 폴더로 **이동**한다 (change directory). `/d` 는 드라이브가 달라도 이동하라는 옵션이다.

> ⚠️ **바탕화면, 문서, OneDrive 폴더는 피하자.** OneDrive가 파일을 자동 동기화하면서 수천 개의 작은 파일을 건드려 설치가 느려지거나 깨질 수 있다.

## 3. 로봇 USB 드라이버 확인

로봇 제어 보드에는 USB 신호를 모터 신호로 바꿔 주는 **변환 칩(CH343 또는 CH340 계열)** 이 들어 있다.
윈도우 10/11은 보통 이 칩을 자동으로 알아보지만, 가끔 드라이버를 직접 깔아야 할 때가 있다.

### 3-1. 연결
1. 팔로워암 제어 보드에 **전원 어댑터**를 꽂는다. (0단계의 전압 주의사항 확인!)
2. 제어 보드와 PC를 **USB 케이블**로 연결한다.

### 3-2. 장치 관리자에서 확인
1. 시작 버튼에 **마우스 오른쪽 클릭 → 장치 관리자**.
2. **포트(COM & LPT)** 항목을 펼친다.

| 보이는 이름 | 의미 | 할 일 |
|---|---|---|
| `USB-SERIAL CH343 (COM4)` / `USB 직렬 장치 (COM4)` / `USB-SERIAL CH340 (COM4)` | ✅ 정상 인식 | 괄호 안 COM 번호를 기억 (3단계에서 다시 확인) |
| **기타 장치** 아래에 노란 ⚠️ 표시 | ❌ 드라이버 없음 | 아래 3-3 진행 |
| 아무것도 안 생김 | 케이블 문제 가능성 | 다른 USB 케이블(데이터용)로 교체, 다른 USB 포트에 꽂기 |

### 3-3. 드라이버 설치 (필요할 때만)
제조사 WCH의 공식 다운로드 페이지에서 받는다.
- CH343 계열: https://www.wch-ic.com/downloads/CH343SER_EXE.html
- CH340/CH341 계열: https://www.wch-ic.com/downloads/CH341SER_EXE.html

어떤 칩인지 모르면 둘 다 설치해도 된다. 설치 후 USB를 뽑았다 다시 꽂고 장치 관리자를 확인한다.

> 💡 충전 전용 USB 케이블은 전기만 통하고 데이터는 못 보낸다. 장치가 전혀 안 잡히면 케이블부터 의심하자.

## 4. NVIDIA 그래픽카드 확인 (AI 학습용)

AI 학습(10단계)은 계산량이 많아 **NVIDIA 그래픽카드(GPU)** 가 있으면 수십 배 빨라진다. 내 PC에 있는지 확인한다.

```bat
nvidia-smi
```

📖 **이 명령은?** NVIDIA 그래픽카드 상태(이름, 메모리, 드라이버 버전)를 보여 주는 프로그램이다. 그래픽카드 드라이버와 함께 설치된다.

| 결과 | 의미 | 기록 |
|---|---|---|
| 표가 나오고 `NVIDIA GeForce RTX ...` 같은 이름이 보임 | GPU 있음 ✅ | 오른쪽 위 `CUDA Version: 12.x` 숫자를 적어 둔다 |
| `'nvidia-smi'은(는) 내부 또는 외부 명령...이 아닙니다` | NVIDIA GPU 없음 또는 드라이버 없음 | 학습은 구글 Colab에서 한다 (10단계 참고) |

> 💡 GPU가 있는데 드라이버가 오래되었다면 https://www.nvidia.com/ko-kr/drivers/ 에서 최신 드라이버로 업데이트하자.
> GPU가 없어도 1~9단계, 11단계는 모두 할 수 있다. 학습만 클라우드에서 하면 된다.
