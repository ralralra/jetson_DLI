# 1️⃣ 초기 설정 ① — VS Code 터미널에서 conda 쓸 수 있게 만들기

## 🎯 이 단계의 목표
- **VS Code 터미널(PowerShell)** 에서 `conda` 명령이 동작하게 만든다.
- 터미널 앞에 `(base)` 가 보이면 이 단계는 끝이다.

## 🤔 왜 이 과정이 필요한가?
LeRobot은 파이썬 프로그램이고, 파이썬 부품 버전을 관리하려고 **conda(Miniforge)** 를 쓴다.
그런데 conda를 설치해도 **VS Code 터미널(PowerShell)은 conda를 바로 알아보지 못한다.** PowerShell이 켜질 때 "conda 준비 코드"가 먼저 실행되어야 하는데, 이 코드는 저절로 등록되지 않기 때문이다.
실습실에서 가장 많이 막히는 지점이 바로 여기다. "`conda` 를 찾을 수 없다", "`conda activate` 를 쳐도 아무 변화가 없다" 같은 문제는 대부분 이 연결이 안 된 것이다. 이 문서의 3단계가 그 연결 작업이다.

---

## ⚠️ 시작 전에 꼭 지킬 것 3가지

1. **명령은 VS Code 터미널에 복사해서 붙여넣는다.** 메뉴 **터미널 → 새 터미널** (단축키 ``Ctrl + ` ``).
2. **터미널 프롬프트가 `PS C:\...>` 로 시작해야 한다.** `PS` 가 PowerShell이라는 표시이다.
   - `C:\...>` 로만 시작하면 cmd, `$` 로 시작하면 Git Bash이다. 터미널 오른쪽 위 `+` 옆 **`˅`** → **PowerShell** 을 고른다.
   - 매번 PowerShell로 열리게 하려면: `Ctrl + Shift + P` → **Terminal: Select Default Profile** → **PowerShell**.
3. **명령은 한 줄씩** 붙여넣고 Enter를 누른다. 여러 줄을 한 번에 붙이면 줄이 합쳐져 엉뚱한 오류가 난다.

---

## 1단계. 작업 폴더 만들고 VS Code로 열기

1. 파일 탐색기에서 `C:\robot` 폴더를 만든다.
   - 한글·띄어쓰기가 없는 짧은 경로가 안전하다.
   - **바탕화면, 문서, OneDrive 폴더는 피한다.** 동기화가 수천 개의 파일을 건드려 설치가 느려지거나 깨질 수 있다.
2. VS Code에서 **파일 → 폴더 열기** → `C:\robot` 선택.
3. 터미널을 열고 현재 위치를 확인한다.

```powershell
pwd
```
📖 **이 명령은?** 지금 터미널이 어느 폴더에 있는지 보여 준다(print working directory). `C:\robot` 이 나오면 된다.

## 2단계. Miniforge(conda) 설치

> 이미 설치되어 있는지 먼저 확인한다.
> ```powershell
> conda --version
> ```
> 버전 숫자가 나오면 **3단계로 건너뛴다.** 빨간 오류가 나와도 설치되어 있을 수 있다(아직 연결이 안 된 것). 시작 메뉴에 **Miniforge Prompt** 나 **Anaconda Prompt** 가 있으면 설치된 것이므로 3단계로 간다.

설치 파일 내려받기:
```powershell
Invoke-WebRequest -Uri "https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-Windows-x86_64.exe" -OutFile "$env:TEMP\Miniforge3.exe"
```
📖 **이 명령은?** Miniforge 설치 파일을 인터넷에서 받아 임시 폴더(`$env:TEMP`)에 저장한다. 몇 분 걸릴 수 있다.

설치 파일 실행:
```powershell
Start-Process "$env:TEMP\Miniforge3.exe" -Wait
```
📖 **이 명령은?** 방금 받은 설치 파일을 실행하고, 설치 창이 닫힐 때까지 기다린다.

설치 창에서는 **기본 설정 그대로** Next → I Agree → **Just Me** → Next → Install → Finish.

> ⚠️ **윈도우 사용자 이름이 한글이거나 띄어쓰기가 있으면**(예: `C:\Users\홍길동`) 설치 위치를 **`C:\miniforge3`** 로 바꾼다. 일부 프로그램이 한글 경로를 못 읽는다.
> 💡 `Invoke-WebRequest` 가 너무 느리거나 실패하면, 웹브라우저로 https://conda-forge.org/download/ 에서 **Windows x86_64** 설치 파일을 직접 받아 더블클릭해도 된다.

## 3단계. PowerShell과 conda 연결 (처음 한 번만)

### ① 스크립트 실행 허용
```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned -Force
```
📖 **이 명령은?** 윈도우는 기본적으로 PowerShell이 스크립트 파일을 실행하지 못하게 막아 둔다. conda 준비 코드도 스크립트이므로, **내 계정에서만** 내 PC의 스크립트를 실행할 수 있게 허용한다. 관리자 권한은 필요 없다.

> ⚠️ 실행 후 `더 구체적인 범위에서 정의된 정책에 의해 재정의되었습니다` 라는 노란 경고가 나오면, **학교 전산 정책으로 막혀 있는 것**이다. 이 문서 맨 아래 **"🆘 PowerShell 연결이 끝내 안 될 때"** 로 간다.

### ② conda 연결 (긴 한 줄을 **통째로 복사해서 한 번만** 실행)
```powershell
$conda = @("$env:USERPROFILE\miniforge3", "$env:USERPROFILE\anaconda3", "$env:USERPROFILE\miniconda3", "C:\miniforge3", "C:\ProgramData\miniforge3", "C:\ProgramData\anaconda3", "C:\ProgramData\miniconda3") | ForEach-Object { "$_\Scripts\conda.exe" } | Where-Object { Test-Path $_ } | Select-Object -First 1; if (-not $conda) { Write-Host "conda를 찾을 수 없습니다. 선생님께 알려주세요." -ForegroundColor Red } else { New-Item -ItemType Directory -Force (Split-Path $PROFILE) | Out-Null; Add-Content -Path $PROFILE -Encoding utf8 -Value "`n#region conda initialize`n(& `"$conda`" `"shell.powershell`" `"hook`") | Out-String | ?{`$_} | Invoke-Expression`n#endregion"; Write-Host "완료: $conda" -ForegroundColor Green }
```
📖 **이 명령은?** 세 가지 일을 한 줄로 처리한다.
1. conda가 설치될 만한 위치를 차례로 뒤져서 `conda.exe` 를 찾는다.
2. PowerShell의 **시작 설정 파일(프로필, `$PROFILE`)** 이 들어갈 폴더를 만든다.
3. 그 파일에 "PowerShell이 켜질 때마다 conda 준비 코드를 실행하라"는 내용을 덧붙인다.

초록색 **`완료: C:\Users\...\miniforge3\Scripts\conda.exe`** 가 나오면 성공이다.

> 💡 원래는 `conda init powershell` 이라는 명령을 쓴다. 그런데 일부 conda 버전(25.11)에서 `No python version information available` 오류로 실패하는 경우가 있어서 ②번 명령으로 대신한다.
> ⚠️ ②번을 여러 번 실행하면 같은 내용이 프로필에 여러 번 들어간다. 동작에는 문제가 없지만, 한 번만 실행하자.

## 4단계. VS Code를 **완전히** 껐다가 다시 켜기

터미널 창만 새로 여는 것으로는 부족하다. **VS Code 창을 모두 닫고** 프로그램을 다시 실행한다.
(VS Code는 처음 켜질 때의 설정을 기억해 두기 때문에, 프로그램 자체를 다시 켜야 3단계 설정을 읽는다.)

다시 켠 뒤 새 터미널을 열면 프롬프트가 이렇게 보여야 한다.
```
(base) PS C:\robot>
```

| 보이는 모습 | 의미 | 할 일 |
|---|---|---|
| `(base) PS C:\robot>` | ✅ 성공 | 5단계로 |
| `PS C:\robot>` (`(base)` 없음) | 프로필이 안 읽힘 | 아래 문제 해결표 확인 |
| 터미널 맨 위에 빨간 글씨 오류 | 프로필 실행이 막힘 | 아래 문제 해결표 확인 |

## 5단계. 로봇 USB 드라이버 확인

1. 팔로워암 제어 보드에 **전원 어댑터**를 꽂고(0단계 전압 주의!), USB로 PC에 연결한다.
2. 시작 버튼 **마우스 오른쪽 클릭 → 장치 관리자 → 포트(COM & LPT)** 를 펼친다.

| 보이는 이름 | 할 일 |
|---|---|
| `USB-SERIAL CH343 (COM3)`, `USB 직렬 장치 (COM3)` 등 | ✅ 정상. 다음으로 |
| **기타 장치** 아래 노란 ⚠️ | 드라이버 설치: [CH343](https://www.wch-ic.com/downloads/CH343SER_EXE.html) / [CH340](https://www.wch-ic.com/downloads/CH341SER_EXE.html) (모르면 둘 다) |
| 아무것도 안 생김 | 다른 USB 케이블로 교체 (충전 전용 케이블은 데이터가 안 통한다) |

## 6단계. 윈도우 개발자 모드 켜기 (AI 학습에 필요)

설정 → **시스템 → 개발자용** (윈도우 10은 **업데이트 및 보안 → 개발자용**) → **개발자 모드 켬**.

> 🤔 **왜?** LeRobot은 학습 중 "가장 최근 저장본"을 가리키는 바로가기(`last` 폴더, 심볼릭 링크)를 만든다. 윈도우는 개발자 모드가 꺼져 있으면 이걸 막아서, 10단계 학습이 `WinError 1314` 오류로 멈춘다.
> 학교 PC라 켤 수 없다면, 학습할 때만 VS Code를 **마우스 오른쪽 클릭 → 관리자 권한으로 실행** 한다.

## 🛠 문제 해결

| 증상 / 오류 메시지 | 원인 | 해결 |
|---|---|---|
| `'Set-ExecutionPolicy' is not recognized...` / `'Set-ExecutionPolicy'은(는) 내부 또는 외부 명령...` | cmd 터미널이다 | 위 "시작 전에" 2번대로 PowerShell로 바꾼다 |
| `conda : 'conda' 용어가 cmdlet, 함수 ... 이름으로 인식되지 않습니다` | conda 미설치, 3단계 미실행, VS Code 재시작 안 함 | 2 → 3 → 4단계 순서대로 다시 |
| 4단계 후에도 `(base)` 가 안 보임 | VS Code 창이 하나라도 남아 있었다 | 작업 표시줄에서 VS Code 창을 **모두** 닫고 다시 켜기 |
| 터미널 맨 위 빨간 글씨 `이 시스템에서 스크립트를 실행할 수 없으므로 ...profile.ps1 파일을 로드할 수 없습니다` | 3단계 ① 이 적용 안 됨 | 3단계 ① 다시 실행. 노란 "재정의" 경고가 나오면 아래 🆘 로 |
| `매개 변수 이름 'Forceconda'...` 처럼 단어가 붙은 오류 | 두 줄이 붙어서 붙여넣어짐 | **한 줄씩** 다시 붙여넣기 |
| `conda를 찾을 수 없습니다` (빨간 글씨) | conda가 다른 위치에 설치됨 | 시작 메뉴 Miniforge Prompt에서 `where conda` 로 위치를 확인해 선생님께 알린다 |
| 프롬프트가 `PS` 인데 VS Code를 켤 때마다 빨간 오류 | 프로필 내용이 깨짐 | `notepad $PROFILE` 로 열어 `#region conda initialize` ~ `#endregion` 이 여러 번 있거나 깨져 있으면 지우고 3단계 ② 다시 |
| `python` 을 치면 Microsoft Store가 열림 | 가상환경 밖에서 윈도우 기본 `python` 이 실행됨 | `conda activate lerobot` 후 다시 (2단계 문서) |

### 🆘 PowerShell 연결이 끝내 안 될 때
학교 PC는 전산 정책으로 PowerShell 스크립트가 막혀 있는 경우가 있다. 이때는 **VS Code 터미널을 cmd로 바꿔서** 진행한다. 이 교재의 명령은 모두 한 줄 형식이라 cmd에서도 그대로 쓸 수 있다.

1. 터미널 오른쪽 위 `+` 옆 `˅` → **Command Prompt** 선택.
2. 터미널을 열 때마다 아래 한 줄을 먼저 실행한다. (Miniforge를 `C:\miniforge3` 에 설치했다면 경로를 바꾼다.)
   ```bat
   "%USERPROFILE%\miniforge3\Scripts\activate.bat"
   ```
   📖 conda 준비 코드를 cmd에서 직접 실행한다. 프롬프트 앞에 `(base)` 가 붙으면 성공이다.
3. 이후 `conda activate lerobot` 부터는 똑같이 진행한다.
4. 단, 명령 안에 `$env:USERPROFILE` 이 있으면 cmd에서는 `%USERPROFILE%` 로 바꿔 쓴다.
