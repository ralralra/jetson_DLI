# 7️⃣ 원격조작 — 리더암으로 팔로워암 움직이기 🎉

## 🎯 이 단계의 목표
- 리더암을 손으로 움직이면 팔로워암이 똑같이 따라 하게 만든다.
- 프로그램을 안전하게 시작하고 멈출 수 있다.

## 🤔 원리는?
프로그램이 1초에 약 60번씩 다음 두 가지를 반복한다.
1. 리더암 모터 6개에게 "지금 몇 도야?" 하고 **읽는다.** (리더암은 모터 힘이 꺼져 있어 손으로 자유롭게 움직인다.)
2. 팔로워암 모터 6개에게 "그 각도로 가!" 하고 **명령한다.**

6단계 캘리브레이션 덕분에 두 팔의 숫자가 같은 의미를 가지므로, 숫자를 그대로 전달해도 같은 자세가 된다.
이렇게 사람이 다른 장치로 로봇을 조종하는 것을 **원격조작(Teleoperation, 텔레오퍼레이션)** 이라고 한다. 9단계에서 AI에게 보여 줄 "시범"도 이 방식으로 만든다.

---

## 1. 실행 전 안전 확인
- [ ] 팔로워암 주변 40cm 안에 물건과 사람 손이 없다.
- [ ] **리더암과 팔로워암을 비슷한 자세**로 맞춰 둔다. 자세가 크게 다르면 시작하는 순간 팔로워가 리더 자세로 **확 움직인다.**
- [ ] 두 팔 전원과 USB가 연결되어 있다.

## 2. 실행

`C:\robot\my_settings.bat` 실행 후:

```bat
lerobot-teleoperate ^
    --robot.type=so101_follower ^
    --robot.port=%FOLLOWER_PORT% ^
    --robot.id=%FOLLOWER_ID% ^
    --teleop.type=so101_leader ^
    --teleop.port=%LEADER_PORT% ^
    --teleop.id=%LEADER_ID%
```

📖 **이 명령은?** 원격조작 프로그램을 실행한다. 옵션이 두 묶음으로 나뉜다.
- `--robot.~` : **따라 하는 쪽**(팔로워암)의 종류·포트·이름
- `--teleop.~` : **조종하는 쪽**(리더암)의 종류·포트·이름
- 이름(`id`)이 6단계와 같으므로, 저장된 캘리브레이션 파일을 자동으로 불러온다. 만약 캘리브레이션 파일이 없으면 이 명령이 **캘리브레이션부터 먼저** 시작한다.

시작할 때 `Press ENTER to use provided calibration file ...` 라고 물으면 **Enter**(저장된 파일 사용)를 누른다.

화면에 관절 이름과 숫자가 계속 바뀌며 표시되면 동작 중이다. 이제 **리더암을 천천히** 움직여 보자!

## 3. 멈추기
- Miniforge Prompt 창을 클릭한 뒤 **Ctrl + C**.
- 종료되면 팔로워암 모터 힘이 풀린다(`disable_torque_on_disconnect` 기본값). **팔이 툭 떨어질 수 있으니 한 손으로 받쳐 준다.**

---

## 4. 해 볼 것 (연습 미션)
1. 리더암을 천천히 움직이며 팔로워가 얼마나 정확히 따라오는지 관찰한다.
2. 리더암의 **트리거(손잡이)** 를 당겨 팔로워의 **그리퍼**를 열고 닫아 본다.
3. 책상 위 지우개를 팔로워로 집어서 옮겨 본다. → 9단계에서 녹화할 동작이다! 미리 손에 익혀 두자.
4. 빠르게 움직이면 어떻게 되는지 관찰한다. (팔로워가 늦게 따라오거나 떨린다. 녹화 때는 **천천히, 일정하게** 움직이는 것이 좋은 이유다.)

## 5. 문제가 생기면
| 증상 | 원인과 해결 |
|---|---|
| 팔로워가 반대 방향으로 움직임 / 한쪽으로 치우침 | 캘리브레이션 자세가 두 팔에서 달랐다 → 6단계를 두 팔 모두 `c` 로 다시 |
| 팔로워가 덜덜 떨림 | 전원 부족 가능성 → 어댑터 사양 확인(0단계), 너무 빠르게 움직이지 않기 |
| `Could not connect on port COM4` | 포트 번호 확인, 다른 Miniforge 창에서 같은 팔을 쓰고 있지 않은지 확인 (한 포트는 한 프로그램만 쓸 수 있다) |
| 그리퍼가 꽉 쥐지 못함 | 정상일 수 있다. LeRobot은 그리퍼 모터 과열을 막으려고 최대 힘을 약 50%로 제한한다 |

- [ ] Ctrl + C로 안전하게 멈출 수 있다.
