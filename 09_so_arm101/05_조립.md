# 5️⃣ 조립 — 영상 보며 관절 하나씩 쌓기

> ⏭️ **조립 완성품을 받았다면 건너뛰고** [06_캘리브레이션.md](./06_캘리브레이션.md) 로 간다.

## 🎯 이 단계의 목표
- 4단계에서 번호를 붙인 모터를 **올바른 자리**에 넣어 팔 두 개를 완성한다.
- 나사 두 종류(M2×6, M3×6)를 구분해서 쓴다.

## 🤔 왜 영상과 함께 보나?
조립은 글보다 눈으로 보는 게 훨씬 빠르다. Hugging Face 공식 문서에는 관절마다 짧은 조립 영상이 있다. 아래 표의 링크를 열어 영상을 **한 번 끝까지 본 뒤**, 다시 틀어 놓고 멈춰 가며 따라 하자.

---

## 1. 시작 전 준비
- **나사 구분**: 가장 작은 나사가 **M2×6mm**(모터를 몸체에 고정), 조금 굵은 나사가 **M3×6mm**(혼·부품 연결).
- **3D 프린팅 부품 정리**: 서포트(지지대) 찌꺼기를 작은 일자 드라이버로 떼어 낸다.
- **케이블 먼저**: 모터를 자리에 넣은 뒤, 다음 단계로 가기 전에 **3핀 케이블을 하나씩 미리 꽂아** 두면 나중에 손이 안 들어가는 문제를 피할 수 있다.
- **모터 혼(horn)**: 모터 축에 끼우는 둥근 원판. 위쪽 혼은 M3×6 나사로 고정하고, 아래쪽 혼은 나사 없이 끼우기만 한다(1~4번 관절 공통).

---

## 2. 관절별 조립 순서 (공식 문서 요약)

| 단계 | 핵심 작업 | 영상 |
|---|---|---|
| Joint 1 (어깨 회전) | 혼 2개 장착 → 1번 모터를 베이스에 넣기 → M2×6 4개(위2·아래2) 고정 → 모터 홀더 끼우고 M2×6 2개 → 어깨 부품을 위 M3×6 4개, 아래 M3×6 4개로 고정 → 어깨 모터 홀더 장착 | [영상](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot/Joint1_v2.mp4) |
| Joint 2 (어깨 들기) | 혼 2개 장착 → 2번 모터를 위에서 밀어 넣기 → M2×6 4개 → 윗팔(upper arm)을 양쪽 M3×6 4개씩 | [영상](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot/Joint2_v2.mp4) |
| Joint 3 (팔꿈치) | 혼 2개 장착 → 3번 모터 넣고 M2×6 4개 → 아랫팔(forearm)을 양쪽 M3×6 4개씩 | [영상](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot/Joint3_v2.mp4) |
| Joint 4 (손목 굽힘) | 혼 2개 장착 → 모터 홀더 4 끼우기 → 4번 모터 넣기 → M2×6 4개 | [영상](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot/Joint4_v2.mp4) |
| Joint 5 (손목 회전) | 5번 모터를 손목 홀더에 넣고 앞쪽 M2×6 2개 → **혼은 1개만** 장착(M3×6) → 손목을 4번 모터에 양쪽 M3×6 4개씩 | [영상](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot/Joint5_v2.mp4) |
| Gripper (팔로워) | 그리퍼를 5번 모터 혼에 M3×6 4개 → 6번 모터 넣고 양쪽 M2×6 2개씩 → 혼 2개 장착 → 집게 발(claw)을 양쪽 M3×6 4개씩 | [영상](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot/Gripper_v2.mp4) |
| Handle (리더) | 리더 홀더를 손목에 M3×6 4개 → 손잡이를 M2×6 1개 → 6번 모터 넣고 양쪽 M2×6 2개씩, 혼은 M3×6 → 트리거를 M3×6 4개 | [영상](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot/Leader_v2.mp4) |

📹 모터 ID 설정 과정 영상(4단계 복습): [setup_motors 영상](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot/setup_motors_so101_2.mp4)

## 3. 마무리 배선
1. 모터끼리 3핀 케이블로 **1번 → 2번 → … → 6번** 차례로 연결한다.
2. **1번 모터(shoulder_pan)** 에서 나온 케이블을 제어 보드에 연결한다.
3. 제어 보드를 팔 베이스에 고정한다.
4. 케이블이 관절 사이에 끼지 않도록, 각 관절을 손으로 끝까지 돌려 보며 여유 길이를 확인한다.

> 🚨 **나사를 너무 세게 조이지 않는다.** 3D 프린팅 부품(플라스틱)은 나사산이 쉽게 뭉개진다. "더 이상 안 돌아가네" 정도에서 멈춘다.
> 💡 조립 후 전원을 넣기 전에, 손으로 모든 관절을 천천히 움직여 걸리는 곳이 없는지 확인한다.
