# 📎 부록 — 명령어 한 장 요약

> 모든 명령은 **Miniforge Prompt** 에서, 먼저 `C:\robot\my_settings.bat` 을 실행한 뒤 입력한다.

## 매번 시작할 때
```bat
C:\robot\my_settings.bat
```

## 단계별 핵심 명령

| 단계 | 명령 | 하는 일 |
|---|---|---|
| 설치 | `conda create -y -n lerobot python=3.12` | 가상환경 만들기 (한 번만) |
| 설치 | `pip install -e ".[feetech,core_scripts,training]"` | LeRobot 설치 (한 번만) |
| 확인 | `lerobot-info` | 설치 정보 출력 |
| 포트 | `lerobot-find-port` | USB 뽑기 전후 비교로 COM 번호 찾기 |
| 모터 | `lerobot-setup-motors --robot.type=so101_follower --robot.port=%FOLLOWER_PORT%` | 모터 ID 설정 (조립 전 한 번만) |
| 캘리브레이션 | `lerobot-calibrate --robot.type=so101_follower --robot.port=%FOLLOWER_PORT% --robot.id=%FOLLOWER_ID%` | 팔로워 0점 맞추기 |
| 캘리브레이션 | `lerobot-calibrate --teleop.type=so101_leader --teleop.port=%LEADER_PORT% --teleop.id=%LEADER_ID%` | 리더 0점 맞추기 |
| 카메라 | `lerobot-find-cameras opencv` | 카메라 번호 찾기 + 사진 저장 |
| 원격조작 | `lerobot-teleoperate ...` | 리더로 팔로워 조종 |
| 녹화 | `lerobot-record ...` | 시범 데이터 녹화 |
| 재생 | `lerobot-replay ...` | 녹화 동작 다시 실행 |
| 학습 | `lerobot-train ...` | AI 학습 |
| 평가 | `lerobot-rollout ...` | AI로 로봇 실행 |

## 원격조작 (카메라 + 화면 표시)
```bat
lerobot-teleoperate ^
    --robot.type=so101_follower --robot.port=%FOLLOWER_PORT% --robot.id=%FOLLOWER_ID% ^
    --robot.cameras="%CAMERAS%" ^
    --teleop.type=so101_leader --teleop.port=%LEADER_PORT% --teleop.id=%LEADER_ID% ^
    --display_data=true
```

## 녹화
```bat
lerobot-record ^
    --robot.type=so101_follower --robot.port=%FOLLOWER_PORT% --robot.id=%FOLLOWER_ID% ^
    --robot.cameras="%CAMERAS%" ^
    --teleop.type=so101_leader --teleop.port=%LEADER_PORT% --teleop.id=%LEADER_ID% ^
    --display_data=true ^
    --dataset.repo_id=%HF_USER%/so101_pick --dataset.no_stamp=true ^
    --dataset.single_task="Put the cube in the box" ^
    --dataset.num_episodes=50 --dataset.episode_time_s=30 --dataset.reset_time_s=15 ^
    --dataset.push_to_hub=false
```
녹화 중 키: **→** 다음 / **←** 다시 찍기 / **Esc** 끝내기

## 학습 (GPU)
```bat
lerobot-train ^
    --dataset.repo_id=%HF_USER%/so101_pick --policy.type=act ^
    --output_dir=outputs/train/act_so101_pick --job_name=act_so101_pick ^
    --policy.device=cuda --policy.push_to_hub=false --wandb.enable=false ^
    --steps=20000 --save_freq=5000
```

## 평가
```bat
lerobot-rollout ^
    --strategy.type=base ^
    --policy.path=outputs/train/act_so101_pick/checkpoints/last/pretrained_model ^
    --robot.type=so101_follower --robot.port=%FOLLOWER_PORT% --robot.id=%FOLLOWER_ID% ^
    --robot.cameras="%CAMERAS%" ^
    --task="Put the cube in the box" --duration=60
```

## 중요한 폴더 위치

| 무엇 | 위치 |
|---|---|
| LeRobot 코드 | `C:\robot\lerobot` |
| 내 설정 파일 | `C:\robot\my_settings.bat` |
| 캘리브레이션 파일 | `%USERPROFILE%\.cache\huggingface\lerobot\calibration` |
| 녹화 데이터 | `%USERPROFILE%\.cache\huggingface\lerobot\내HF_USER\데이터셋이름` |
| 카메라 테스트 사진 | `C:\robot\lerobot\outputs\captured_images` |
| 학습된 모델 | `C:\robot\lerobot\outputs\train\act_so101_pick\checkpoints\last\pretrained_model` |

## 리눅스 자료를 윈도우로 바꿔 읽는 법
인터넷의 LeRobot 자료는 대부분 리눅스·맥 기준이다. 다음만 바꾸면 윈도우에서도 쓸 수 있다.

| 리눅스·맥 자료 | 윈도우(이 교재) |
|---|---|
| 줄 끝 `\` | 줄 끝 `^` |
| `/dev/ttyACM0`, `/dev/tty.usbmodem...` | `COM3`, `COM4` … |
| `sudo chmod 666 /dev/ttyACM0` | **필요 없음** (윈도우는 권한 설정이 없다) |
| `${HF_USER}`, `$HF_USER` | `%HF_USER%` |
| `HF_USER=$(hf auth whoami ...)` | `set "HF_USER=내아이디"` |
| `~/.cache/huggingface/...` | `%USERPROFILE%\.cache\huggingface\...` |
| `--robot.port=/dev/ttyACM1` | `--robot.port=%FOLLOWER_PORT%` |
| 카메라 `index_or_path: /dev/video0` | `index_or_path: 0` |
