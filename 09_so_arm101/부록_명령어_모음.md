# 📎 부록 — 명령어 한 장 요약

> 모든 명령은 **VS Code 터미널(PowerShell)** 에서 **한 줄씩** 붙여넣는다.
> 예시 값: 팔로워 포트 `COM3`, 리더 포트 `COM4`, 카메라 front `0` / side `1`. 내 번호로 바꿔 쓴다.

## 매번 시작할 때
```powershell
conda activate lerobot
```
```powershell
cd C:\robot\lerobot
```

## 단계별 핵심 명령

| 단계 | 명령 | 하는 일 |
|---|---|---|
| 확인 | `lerobot-info` | 설치 정보 출력 |
| 포트 | `lerobot-find-port` | USB 뽑기 전후 비교로 COM 번호 찾기 |
| 모터 | `lerobot-setup-motors --robot.type=so101_follower --robot.port=COM3` | 팔로워 모터 ID 설정 (조립 전 한 번만) |
| 모터 | `lerobot-setup-motors --teleop.type=so101_leader --teleop.port=COM4` | 리더 모터 ID 설정 (조립 전 한 번만) |
| 캘리브레이션 | `lerobot-calibrate --robot.type=so101_follower --robot.port=COM3 --robot.id=my_follower` | 팔로워 0점 맞추기 |
| 캘리브레이션 | `lerobot-calibrate --teleop.type=so101_leader --teleop.port=COM4 --teleop.id=my_leader` | 리더 0점 맞추기 |
| 카메라 | `lerobot-find-cameras opencv` | 카메라 번호 찾기 + 사진 저장 |

## 원격조작 (카메라 없이)
```powershell
lerobot-teleoperate --robot.type=so101_follower --robot.port=COM3 --robot.id=my_follower --teleop.type=so101_leader --teleop.port=COM4 --teleop.id=my_leader
```

## 원격조작 (카메라 + 화면 표시)
```powershell
lerobot-teleoperate --robot.type=so101_follower --robot.port=COM3 --robot.id=my_follower --robot.cameras="{ front: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30}, side: {type: opencv, index_or_path: 1, width: 640, height: 480, fps: 30}}" --teleop.type=so101_leader --teleop.port=COM4 --teleop.id=my_leader --display_data=true
```

## 녹화
```powershell
lerobot-record --robot.type=so101_follower --robot.port=COM3 --robot.id=my_follower --robot.cameras="{ front: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30}, side: {type: opencv, index_or_path: 1, width: 640, height: 480, fps: 30}}" --teleop.type=so101_leader --teleop.port=COM4 --teleop.id=my_leader --display_data=true --dataset.repo_id=student/so101_pick --dataset.no_stamp=true --dataset.single_task="Put the cube in the box" --dataset.num_episodes=50 --dataset.episode_time_s=30 --dataset.reset_time_s=15 --dataset.push_to_hub=false
```
녹화 중 키: **→** 다음 / **←** 다시 찍기 / **Esc** 끝내기

## 학습 (GPU)
```powershell
lerobot-train --dataset.repo_id=student/so101_pick --policy.type=act --output_dir=outputs/train/act_so101_pick --job_name=act_so101_pick --policy.device=cuda --policy.push_to_hub=false --wandb.enable=false --steps=20000 --save_freq=5000
```

## 평가
```powershell
lerobot-rollout --strategy.type=base --policy.path=outputs/train/act_so101_pick/checkpoints/last/pretrained_model --robot.type=so101_follower --robot.port=COM3 --robot.id=my_follower --robot.cameras="{ front: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30}, side: {type: opencv, index_or_path: 1, width: 640, height: 480, fps: 30}}" --task="Put the cube in the box" --duration=60
```

## 중요한 폴더 위치
파일 탐색기 주소창에 붙여넣으면 바로 열린다.

| 무엇 | 위치 |
|---|---|
| LeRobot 코드 | `C:\robot\lerobot` |
| 캘리브레이션 파일 | `%USERPROFILE%\.cache\huggingface\lerobot\calibration` |
| 녹화 데이터 | `%USERPROFILE%\.cache\huggingface\lerobot\student\데이터셋이름` |
| 카메라 테스트 사진 | `C:\robot\lerobot\outputs\captured_images` |
| 학습된 모델 | `C:\robot\lerobot\outputs\train\act_so101_pick\checkpoints\last\pretrained_model` |

## 리눅스 자료를 윈도우로 바꿔 읽는 법
인터넷의 LeRobot 자료는 대부분 리눅스·맥 기준이다. 다음만 바꾸면 VS Code PowerShell에서도 쓸 수 있다.

| 리눅스·맥 자료 | 윈도우(이 교재) |
|---|---|
| 줄 끝 `\` 로 여러 줄에 나눈 명령 | `\` 를 지우고 **한 줄로** 이어 붙인다 |
| `/dev/ttyACM0`, `/dev/tty.usbmodem...` | `COM3`, `COM4` … |
| `sudo chmod 666 /dev/ttyACM0` | **필요 없음** (윈도우는 이 권한 설정이 없다) |
| `${HF_USER}`, `$HF_USER` | 내 아이디를 직접 쓴다 (예: `student`) |
| `~/.cache/huggingface/...` | `$env:USERPROFILE\.cache\huggingface\...` |
| 카메라 `index_or_path: /dev/video0` | `index_or_path: 0` |
