# 🦾 SO-ARM101 로봇팔 × LeRobot — 윈도우 실습 교재

> 브레인어스(Brain Us) **AI Robot ARM Edu Kit**(SO-101 기반, 리더암 1 + 팔로워암 1 + 카메라 2)를
> **윈도우 PC 한 대**로 설치부터 AI 학습·평가까지 따라 하는 교재이다.
> 리눅스·젯슨·맥 내용은 모두 뺐고, 처음 접하는 고등학생도 순서대로만 하면 끝까지 갈 수 있도록 정리하였다.

---

## 🧭 이 교재로 무엇을 하게 되나

사람이 **리더암(검은 팔, 손으로 움직이는 팔)** 을 움직이면 **팔로워암(흰 팔, 모터가 힘을 내는 팔)** 이 똑같이 따라 움직인다.
이 장면을 카메라로 녹화해 50번 정도 모으면, AI가 "이런 화면일 때는 팔을 이렇게 움직이는구나"를 배운다.
마지막에는 사람이 손을 떼도 **팔로워암 혼자서** 같은 일을 해낸다. 이것을 **모방 학습(Imitation Learning)** 이라고 한다.

```
[1] 설치  →  [2] 로봇과 연결  →  [3] 따라 하기(원격조작)  →  [4] 녹화(데이터)  →  [5] AI 학습  →  [6] AI 혼자 동작(평가)
```

## 📌 이 교재의 기준 버전 (중요!)

| 항목 | 이 교재 기준 | 이유 |
|---|---|---|
| 운영체제 | Windows 10 / 11 (64비트) | 실습실 PC 기준 |
| 파이썬 배포판 | Miniforge3 | LeRobot 공식 설치 문서가 권장 |
| 파이썬 | 3.12 | LeRobot 0.6.x가 3.12 이상을 요구 |
| LeRobot | **v0.6.1** (2026-08 공개) 로 고정 | 최신 코드는 명령어가 자주 바뀌므로 버전을 고정 |

LeRobot은 매우 빠르게 바뀌는 오픈소스이다. 인터넷 강좌마다 명령어가 조금씩 다른 이유가 바로 이것이다.
예를 들어 2025년 자료에는 `python lerobot/scripts/control_robot.py ...` 같은 옛 명령이 나오지만, 지금은 `lerobot-record` 처럼 바뀌었다.
그래서 이 교재는 **v0.6.1 소스코드를 직접 확인**하여 명령어와 옵션 이름을 맞추었다. 다른 버전을 쓰면 일부 옵션 이름이 다를 수 있다.
