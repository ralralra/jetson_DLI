# 🆘 문제해결 — 자주 나는 오류와 해결법

> 사용법: 오류 메시지의 **마지막 줄**에서 핵심 단어를 골라 이 페이지에서 **Ctrl + F** 로 찾는다.

## 1. 설치·환경 문제

| 오류 / 증상 | 원인 | 해결 |
|---|---|---|
| `'conda'은(는) 내부 또는 외부 명령...이 아닙니다` | 일반 명령 프롬프트·PowerShell을 열었다 | 시작 메뉴에서 **Miniforge Prompt** 를 연다 |
| `'lerobot-calibrate'은(는) 내부 또는 외부 명령...` | 가상환경에 안 들어갔다 (`(base)` 상태) | `conda activate lerobot` 또는 `C:\robot\my_settings.bat` |
| `ERROR: Package 'lerobot' requires a different Python` | 파이썬 버전이 3.12 미만 | `conda create -y -n lerobot python=3.12` 로 환경을 새로 만든다 |
| `pip install -e` 중 `Microsoft Visual C++ 14.0 or greater is required` | 일부 부품을 직접 빌드해야 하는데 C++ 빌드 도구가 없다 | "Visual Studio Build Tools"를 설치하고 "C++를 사용한 데스크톱 개발"을 선택 후 재시도 |
| `torch.cuda.is_available()` 이 `False` (GPU 있는 PC) | CPU용 PyTorch가 설치됨 | 2단계 4번 명령 끝에 `--force-reinstall` 을 붙여 다시 실행 |
| `ffmpeg` 관련 오류, `No valid stream found in input file` | ffmpeg가 없거나 버전 불일치 | `conda install -y -c conda-forge ffmpeg` / 계속되면 `conda install -y -c conda-forge ffmpeg=7.1.1` |
| 설치가 매우 느리거나 중간에 멈춤 | OneDrive·바탕화면 경로, 백신 실시간 검사 | 작업 폴더를 `C:\robot` 으로, 설치하는 동안 잠시 기다린다 |

## 2. 포트·모터 문제

| 오류 / 증상 | 원인 | 해결 |
|---|---|---|
| `Could not detect the port. No difference was found` | Enter 전에 USB를 안 뽑았다 | 다시 실행하고, **뽑은 뒤** Enter |
| `Could not connect on port 'COM4'` / `PermissionError ... 액세스가 거부되었습니다` | 포트 번호가 틀렸거나 **다른 프로그램이 이미 그 포트를 사용 중** | `echo %FOLLOWER_PORT%` 로 확인, 다른 Miniforge 창·Feetech 프로그램 종료, USB 뽑았다 꽂기 |
| `FileNotFoundError ... COM4` | 그 포트에 장치가 없다 (USB 구멍이 바뀜) | `lerobot-find-port` 로 다시 찾고 bat 파일 수정 |
| `Motor 'gripper' was not found` / `Missing motor IDs` | 모터 케이블 빠짐, **전원 미연결·전압 부족**, ID 미설정 | 전원 어댑터 확인 → 케이블 재연결 → (조립품이 아니라면) 4단계 ID 설정 |
| `There is no status packet!` | 해당 팔 전원 또는 모터 데이터선 불량 | 전원, 3핀 케이블을 딸깍 소리 나게 다시 꽂기 |
| `Magnitude 30841 exceeds 2047 ...` | 모터 위치값 이상 | 전원을 껐다 켠 후 재시도. 계속되면 해당 모터 ID·중앙값 재설정 (Juxi FAQ) |
| 장치 관리자에 노란 ⚠️ | USB 드라이버 없음 | 1단계 3-3, WCH CH343/CH340 드라이버 설치 |

## 3. 캘리브레이션·원격조작 문제

| 오류 / 증상 | 원인 | 해결 |
|---|---|---|
| `Some motors have the same min and max values` | 캘리브레이션 때 어떤 관절을 안 움직였다 | 다시 실행해서 5개 관절 모두 끝까지 움직이기 |
| 실행할 때마다 캘리브레이션을 새로 하자고 함 | `--robot.id` / `--teleop.id` 이름이 6단계와 다르다 | bat 파일의 `FOLLOWER_ID`, `LEADER_ID` 확인 |
| 팔로워가 리더와 다른 각도로 움직임 | 두 팔의 가운데 자세가 달랐다 | 6단계를 두 팔 모두 `c` 로 다시 |
| 시작하자마자 팔로워가 확 움직임 | 리더·팔로워 자세 차이가 컸다 | 실행 전 두 팔 자세를 비슷하게 맞추기 |

## 4. 카메라 문제

| 오류 / 증상 | 원인 | 해결 |
|---|---|---|
| `No opencv cameras were detected` | 윈도우 카메라 권한 꺼짐 | 설정 → 개인 정보 및 보안 → 카메라 → 데스크톱 앱 허용 켜기 |
| `Failed to open` / 화면이 검음 | 다른 프로그램이 카메라 사용 중 | 줌·팀즈·카메라 앱 종료 |
| fps 경고, 화면 끊김 | USB 대역폭 부족 | 카메라를 다른 USB 포트로 분산, 해상도 640×480 |
| 카메라 번호가 바뀜 | USB 구멍을 바꿔 꽂음 | `lerobot-find-cameras opencv` 다시 실행 |

## 5. 녹화·학습·평가 문제

| 오류 / 증상 | 원인 | 해결 |
|---|---|---|
| `FileExistsError` (녹화 시작 시) | 같은 이름의 데이터셋 폴더가 이미 있음 | 이어서 찍기: `--resume=true` + `--dataset.root=...` (9단계 5번) / 새로: 폴더 삭제 또는 이름 변경 |
| `resume() requires an explicit 'root' directory` | 이어 녹화에 폴더 위치를 안 알려 줌 | `--dataset.root="%USERPROFILE%\.cache\huggingface\lerobot\%HF_USER%\데이터셋이름"` 추가 |
| 데이터셋 이름 뒤에 `_20261008_...` 이 붙음 | `--dataset.no_stamp=true` 를 빼먹음 | 학습 때 붙은 이름 그대로 쓰거나, 옵션을 넣고 다시 녹화 |
| `Dataset names starting with 'eval_' are reserved` | 녹화(`lerobot-record`)에 `eval_` 이름을 씀 | 녹화용 이름은 `eval_` 없이 |
| 화살표 키가 안 먹음 | 다른 창이 선택됨 / 한글 입력 상태에서 `n`,`r`,`q` 사용 | 화살표 키 사용, 녹화 중에는 다른 프로그램 클릭하지 않기 |
| `'repo_id' argument missing` (학습) | 모델 업로드 설정이 켜져 있음 | `--policy.push_to_hub=false` 추가 |
| `Output directory ... already exists` (학습) | 같은 출력 폴더가 있음 | 폴더 이름 변경, 또는 10단계의 이어서 학습 명령(`--config_path=.../train_config.json --resume=true`) |
| `A config_path is expected when resuming a run` | `--resume=true` 만 쓰고 `--config_path` 를 빠뜨림 | 10단계의 이어서 학습 명령 그대로 사용 |
| `OSError: [WinError 1314]` (학습 중 5,000스텝 근처) | 윈도우가 `last` 바로가기(심볼릭 링크) 생성을 막음 | 1단계 5번 **개발자 모드** 켜기(또는 관리자 권한 실행) 후, `--config_path=outputs/train/act_so101_pick/checkpoints/005000/pretrained_model/train_config.json --resume=true` 처럼 **번호 폴더**로 이어서 학습 |
| `last` 폴더가 없음 / 열리지 않음 (평가) | 위와 같은 원인 | `checkpoints\020000\pretrained_model` 처럼 번호 폴더를 직접 지정 |
| `Your dataset must be tagged with a codebase version` (Colab) | `hf upload` 로 올린 데이터에 버전 이름표가 없음 | 10단계 B-2의 `create_tag` 명령 실행 |
| `CUDA out of memory` | 그래픽카드 메모리 부족 | `--batch_size=4` 처럼 줄이기 |
| 학습 시작 직후 `DataLoader` / `worker` 관련 오류 | 윈도우의 멀티프로세스 데이터 로딩 문제 | `--num_workers=0` 추가 (느려지지만 안정적) |
| 평가 중 `mean is infinity` 또는 이상한 동작 | 녹화 때와 **카메라 이름이 다름** | `front`, `side` 이름을 녹화 때와 똑같이 |

## 6. 그래도 안 되면
1. 창을 닫고 **Miniforge Prompt를 새로** 연 뒤 `C:\robot\my_settings.bat` 부터 다시 한다.
2. 두 팔의 **전원과 USB를 모두 뽑았다가** 다시 꽂는다.
3. 가상환경을 새로 만든다 (최후의 방법):
   ```bat
   conda deactivate
   conda remove -y -n lerobot --all
   ```
   📖 `lerobot` 가상환경을 통째로 지운다. 이후 2단계를 처음부터 다시 한다. 캘리브레이션 파일과 녹화 데이터는 `%USERPROFILE%\.cache\huggingface\lerobot` 에 따로 있으므로 지워지지 않는다.
4. 오류 메시지 전체를 복사해 선생님께, 또는 LeRobot 디스코드(https://discord.com/invite/s3KuuzsPFb)에 질문한다.
