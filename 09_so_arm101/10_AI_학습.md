# 🔟 AI 학습 — 녹화한 시범으로 ACT 모델 훈련하기

## 🎯 이 단계의 목표
- 9단계에서 모은 데이터로 **ACT** 모델을 학습시킨다.
- 학습 로그에서 **loss(손실)** 가 줄어드는 것을 읽을 수 있다.
- 내 PC에 GPU가 없으면 **구글 Colab** 으로 학습할 수 있다.

## 🤔 학습이란 무엇인가?
AI 모델은 처음엔 아무것도 모르는 "빈 두뇌"이다. 학습은 다음을 수만 번 반복하는 과정이다.
1. 녹화 데이터에서 한 장면(카메라 2장 + 팔 자세)을 꺼내 AI에게 보여 준다.
2. AI가 "다음엔 팔을 이렇게 움직이겠다"고 **예측**한다.
3. 실제로 사람이 움직인 **정답**(리더암 각도)과 비교해 얼마나 틀렸는지 계산한다. 이 "틀린 정도"가 **loss(손실)** 이다.
4. 덜 틀리도록 AI 내부 숫자를 아주 조금 고친다.

이 반복 1번을 **step(스텝)** 이라고 한다. loss가 점점 줄어들면 AI가 사람의 시범을 닮아 가고 있다는 뜻이다.

### ACT는 어떤 모델인가?
**ACT(Action Chunking with Transformers)** 는 한 번에 동작 하나가 아니라 **앞으로의 동작 여러 개를 한 덩어리(chunk)로** 예측한다. LeRobot v0.6.1의 기본값은 한 번에 100개 동작이다.
사람도 컵을 잡을 때 "손 뻗고 → 쥐고 → 들기"를 한 흐름으로 계획하듯, 덩어리로 예측하면 동작이 더 **부드럽고 덜 흔들린다.** 데이터 50개 정도로도 학습이 잘 되는 편이라 입문용으로 널리 쓰인다.

## 어떤 방법으로 학습할까?

| 내 상황 | 방법 |
|---|---|
| `nvidia-smi` 가 나오고 2단계에서 `torch.cuda.is_available()` 이 `True` | **방법 A** — 내 PC에서 학습 |
| GPU 없음 / 학교 PC 사용 제한 | **방법 B** — 구글 Colab(클라우드 GPU)에서 학습 |

> 💡 GPU 없이 CPU로 학습하는 것도 기술적으로는 가능(`--policy.device=cpu`)하지만, 매우 느려서 수업 시간 안에 끝내기 어렵다.

---

## 방법 A — 내 PC(NVIDIA GPU)에서 학습

`C:\robot\my_settings.bat` 실행 후:

```bat
lerobot-train ^
    --dataset.repo_id=%HF_USER%/so101_pick ^
    --policy.type=act ^
    --output_dir=outputs/train/act_so101_pick ^
    --job_name=act_so101_pick ^
    --policy.device=cuda ^
    --policy.push_to_hub=false ^
    --wandb.enable=false ^
    --steps=20000 ^
    --save_freq=5000
```

📖 **이 명령은?** 학습 프로그램을 실행한다.

| 옵션 | 뜻 |
|---|---|
| `--dataset.repo_id=%HF_USER%/so101_pick` | 9단계에서 녹화한 데이터셋 이름. 내 PC에 있으면 그걸 먼저 쓴다 |
| `--policy.type=act` | ACT 모델로 학습. 카메라 수·관절 수는 데이터에서 자동으로 맞춘다 |
| `--output_dir=outputs/train/act_so101_pick` | 학습 결과를 저장할 폴더 (`C:\robot\lerobot\outputs\train\act_so101_pick`) |
| `--job_name=...` | 이번 학습의 이름표 |
| `--policy.device=cuda` | **GPU로** 계산. (CPU면 `cpu`) |
| `--policy.push_to_hub=false` | 학습된 모델을 인터넷에 올리지 않음. 이 옵션이 없으면 업로드할 이름(`repo_id`)을 요구하며 오류가 난다 |
| `--wandb.enable=false` | 온라인 학습 그래프 서비스(Weights & Biases) 사용 안 함 |
| `--steps=20000` | 학습 반복 횟수. LeRobot 기본값은 100,000 |
| `--save_freq=5000` | 5,000스텝마다 중간 저장(체크포인트) |

> 🤔 **왜 20,000스텝인가?** 수업 시간 안에 결과를 보기 위한 **첫 시도용 값**이다. 결과가 아쉬우면 스텝을 늘려 다시 학습한다. 참고로 Hugging Face 문서에 따르면 100,000스텝은 NVIDIA A100 GPU(배치 64)에서 약 1.5시간 걸린다. 일반 PC 그래픽카드는 이보다 훨씬 오래 걸린다.

### 학습 로그 읽는 법
200스텝마다 이런 줄이 출력된다.
```
step:2K smpl:16K ep:45 epch:1.20 loss:0.312 grdn:12.345 lr:1.0e-05 updt_s:0.150 data_s:0.010
```
| 항목 | 뜻 | 보는 법 |
|---|---|---|
| `step` | 지금까지 반복 횟수 | 목표(20K)까지 올라간다 |
| `epch` | 전체 데이터를 몇 바퀴 봤는지 | |
| **`loss`** | **틀린 정도** | **점점 작아지면 잘 배우는 중** ✅ |
| `updt_s` | 한 스텝 계산에 걸린 초 | 남은 시간 어림에 쓴다 |

> ⚠️ 위 숫자는 형식을 보여 주기 위한 예시이다. 실제 값은 데이터와 PC에 따라 다르다.

### 결과물 위치
```
C:\robot\lerobot\outputs\train\act_so101_pick\checkpoints\
    005000\pretrained_model\
    010000\pretrained_model\
    ...
    last\pretrained_model\      ← 가장 마지막 저장본 (11단계에서 사용)
```

### 중간에 끊겼다면 — 이어서 학습
```bat
lerobot-train ^
    --config_path=outputs/train/act_so101_pick/checkpoints/last/pretrained_model/train_config.json ^
    --resume=true
```
📖 마지막 저장본의 설정 파일을 읽어서 **그 지점부터** 학습을 이어 간다.

> ⚠️ 같은 `--output_dir` 로 **처음부터** 다시 학습하면 `Output directory ... already exists` 오류가 난다. 폴더 이름을 바꾸거나(`act_so101_pick2`) 기존 폴더를 지운다.

## 방법 B — 구글 Colab에서 학습 (GPU 없는 PC)

Colab은 구글이 웹브라우저에서 무료로 GPU를 빌려주는 서비스이다. 데이터를 **Hugging Face에 올리고 → Colab에서 학습하고 → 모델을 다시 Hugging Face에 올린 뒤 → 내 PC에서 받아 쓰는** 흐름이다.

### B-1. Hugging Face 계정과 토큰 만들기
1. https://huggingface.co 에서 회원가입한다. (학생이라면 보호자·선생님과 상의)
2. https://huggingface.co/settings/tokens 에서 **New token → Type: Write** 로 토큰을 만들고 복사해 둔다.
   - 토큰은 **비밀번호와 같다.** 다른 사람에게 보여 주거나 깃허브에 올리지 않는다.
3. `C:\robot\my_settings.bat` 의 `HF_USER` 를 **내 Hugging Face 아이디**로 바꾸고 다시 실행한다.

### B-2. 내 PC에서 로그인하고 데이터 올리기
```bat
hf auth login
```
📖 **이 명령은?** Hugging Face에 로그인한다. 토큰을 붙여넣으라고 하면 **마우스 오른쪽 클릭**으로 붙여넣고 Enter. (보안상 화면에 글자가 안 보이는 게 정상이다.) git 자격 증명 질문에는 `n` 을 눌러도 된다.

```bat
hf auth whoami
```
📖 로그인된 아이디를 보여 준다. 내 아이디가 나오면 성공.

```bat
hf upload %HF_USER%/so101_pick %USERPROFILE%\.cache\huggingface\lerobot\student\so101_pick --repo-type dataset
```
📖 **이 명령은?** 내 PC의 데이터셋 폴더를 Hugging Face의 `내아이디/so101_pick` **데이터셋 저장소**로 올린다.
- 9단계에서 녹화할 때 `HF_USER` 가 `student` 였다면 폴더 경로에 `student` 가 들어간다. 녹화할 때 이미 내 아이디로 바꿨다면 경로의 `student` 를 내 아이디로 고친다.
- 업로드된 데이터는 https://huggingface.co/datasets/내아이디/so101_pick 에서 볼 수 있다. 기본은 **공개**이므로, 얼굴 등 개인정보가 카메라에 찍히지 않았는지 확인하자.

### B-3. Colab에서 학습
1. 공식 ACT 학습 노트북을 연다: https://colab.research.google.com/github/huggingface/notebooks/blob/main/lerobot/training-act.ipynb
2. 메뉴 **런타임 → 런타임 유형 변경 → T4 GPU** 를 선택한다.
3. 노트북의 안내대로 셀을 차례로 실행하되, 데이터셋 이름을 `내아이디/so101_pick` 으로 바꾼다.
4. 학습 명령에 다음 두 옵션이 있는지 확인한다. 학습이 끝나면 모델이 자동으로 Hugging Face에 올라간다.
   ```
   --policy.push_to_hub=true --policy.repo_id=내아이디/act_so101_pick
   ```

> ⚠️ Colab 무료 GPU는 사용 시간 제한이 있고, 오래 쓰면 연결이 끊긴다. 스텝 수를 줄여(예: `--steps=20000`) 먼저 결과를 보자.
> ⚠️ 노트북 내용은 Hugging Face가 수시로 갱신한다. 노트북의 LeRobot 버전과 내 PC의 버전(v0.6.1)이 크게 다르면, 모델을 불러올 때 오류가 날 수 있다. 오류가 나면 노트북 첫 셀의 설치 명령에서 `git checkout v0.6.1` 을 추가해 버전을 맞춘다.
