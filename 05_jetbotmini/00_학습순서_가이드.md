## 4부. 메인 실습 — 젯봇의 꽃 🌸 (순서대로!)

> ⚠️ **시작 전 필수** : 야붐 이미지는 **앱 조종 프로세스가 자동 실행**되어 있어서, 노트북 예제와 리소스가 충돌합니다. 6.1 PDF 안내대로 먼저 꺼주세요:
> ```bash
> sudo systemctl stop jetbotmini_start      # 이번만 끄기
> sudo systemctl disable jetbotmini_start   # 부팅 시 자동실행 끄기 (실습 기간 동안 권장)
> # 실습 끝나고 앱 조종을 다시 쓰려면: sudo systemctl enable jetbotmini_start
> ```
