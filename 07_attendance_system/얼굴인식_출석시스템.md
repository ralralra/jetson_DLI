# 🙋 얼굴인식 출석 시스템 만들기 (Jetson + Face Recognition)

> 카메라 앞에 서면 얼굴을 인식해서 **자동으로 출석부(CSV)에 이름·시간·날짜를 기록**하는 시스템입니다.
> DLI 과정에서 배운 카메라·이미지 처리를 실제 생활에 응용하는 프로젝트입니다.
>
> 원본 프로젝트 : https://github.com/VK-Ant/AttendanceSystem-JetsonAGX
> (Jetson AGX Xavier용으로 만들어졌지만, 아래 주의사항을 지키면 **젯슨나노에서도 동작**합니다)

---

## 1. 어떤 원리인가요?

`face_recognition` 라이브러리(내부는 **dlib**)를 사용합니다:

1. **얼굴 검출** — 카메라 화면에서 얼굴 위치를 찾는다
2. **얼굴 인코딩** — 찾은 얼굴을 숫자 128개(128차원 벡터)로 요약한다
   - 💡 DLI 과정에서 배운 개념과 연결됩니다: ResNet-18이 이미지를 512개 숫자(특징)로 요약했던 것처럼, 얼굴도 "특징 숫자들"로 바꿔서 비교하는 겁니다!
3. **거리 비교** — 등록해둔 얼굴의 인코딩과 새 얼굴의 인코딩 사이 거리를 계산해서, 가까우면 "같은 사람"으로 판정
4. **기록** — 인식된 이름 + 시간 + 날짜를 `Attendance_(날짜).csv` 파일에 저장

## 2. 준비물

- 젯슨나노 (2GB 가능) + **USB 카메라** (`/dev/video0` — DLI 과정에서 쓰던 그대로)
- **스왑 설정 완료** 상태 (👉 [DLI 가이드 8단계](../01_jetson_dli_course/0_DLI_수료과정_가이드.md)) — **2GB는 필수!** dlib 컴파일 때 메모리가 모자라면 중간에 죽습니다.
- 화면(GUI 모드) — 인식 결과 창(`cv2.imshow`)을 띄우므로 headless가 아닌 **GUI 모드**에서 실행하세요:
  ```bash
  sudo systemctl set-default graphical.target
  sudo reboot
  ```

## 3. 설치

### 3-1. 빌드 도구와 라이브러리 설치

```bash
sudo apt-get update
sudo apt-get install -y cmake libopenblas-dev liblapack-dev libjpeg-dev python3-pip
```

### 3-2. dlib & face_recognition 설치 (⏰ 오래 걸림 주의!)

```bash
pip3 install dlib          # 나노에서 1~3시간 걸릴 수 있음 (소스 컴파일)
pip3 install face_recognition
pip3 install pytz
```

> ⚠️ **주의 1** : `pip3 install dlib`은 젯슨나노에서 소스를 직접 컴파일하므로 **몇 시간** 걸릴 수 있습니다.
> 쿨링팬을 켜두고, 수업 끝나기 전에 미리 걸어두거나 밤에 돌려두세요.
> 중간에 죽으면 스왑이 켜져 있는지 `free -h`로 확인하세요.
>
> ⚠️ **주의 2** : OpenCV는 **설치하지 마세요!** JetPack에 젯슨용 OpenCV가 이미 들어 있습니다.
> 원본 저장소의 `requirement.txt`를 그대로 설치하면(`pip3 install -r requirement.txt`)
> PC용 opencv-python이 덮어써서 오히려 문제가 생길 수 있습니다. 위 명령처럼 **필요한 것만 골라 설치**합니다.
> 확인: `python3 -c "import cv2; print(cv2.__version__)"` 가 잘 나오면 OK.

### 3-3. 프로젝트 내려받기

```bash
cd ~
git clone https://github.com/VK-Ant/AttendanceSystem-JetsonAGX.git
cd AttendanceSystem-JetsonAGX
ls
# Attendance_data/  Attendance_Entry/  initial_data_capture.py  main.py  run.sh ...
```

## 4. 사용법

### 4-1. 내 얼굴 등록하기

```bash
python3 initial_data_capture.py
```

- `Please Enter your name:` 이 나오면 **영어로 이름 입력** (예: `hong`)
- 카메라가 자동으로 사진을 찍어 `Attendance_data/hong.png` 로 저장합니다.
- 반 친구들도 한 명씩 등록하세요. (등록된 사진은 `Attendance_data/` 폴더에서 확인)
- 잘못 등록했으면: `python3 delete_image.py` 로 삭제

> 💡 팁 : 정면을 보고, 얼굴이 화면 가운데 크게 나오게 찍으세요. 조명이 어두우면 인식률이 떨어집니다.

### 4-2. 출석 시스템 실행!

```bash
python3 main.py        # 또는 bash run.sh
```

- 카메라 창이 뜨고, 등록된 사람이 화면에 나타나면 **이름표가 붙습니다.**
- 동시에 `Attendance_Entry/Attendance_(날짜).csv` 파일에 `번호, 시간, 날짜`와 이름이 기록됩니다.
- 종료는 카메라 창을 클릭한 뒤 **`q`** 키.

### 4-3. 출석부 확인

```bash
cd Attendance_Entry
ls                     # Attendance_2026_... .csv
cat Attendance_*.csv   # 터미널에서 바로 확인
```

CSV 파일은 컴퓨터로 옮겨서 엑셀로 열면 그대로 출석부가 됩니다. 📋

## 5. 젯슨나노 2GB에서 잘 돌리는 요령

| 증상 | 해결 |
|---|---|
| dlib 설치 중 멈춤/죽음 | 스왑 확인(`free -h`), 쿨링팬 켜기, 다른 프로그램 모두 종료 |
| 실행이 너무 느림 | 얼굴 검출은 기본 `hog` 모델 사용 (cnn 모델은 2GB에서 무리). 카메라 해상도를 낮추면 빨라짐 |
| 카메라 창이 안 뜸 | GUI 모드인지 확인 (`sudo systemctl set-default graphical.target` 후 재부팅) |
| `/dev/video0` 없음 | USB 카메라 연결 확인: `ls /dev/video0 -l` |
| 인식이 자꾸 틀림 | 등록 사진을 밝은 곳에서 정면으로 다시 찍기 (`delete_image.py` 후 재등록) |
