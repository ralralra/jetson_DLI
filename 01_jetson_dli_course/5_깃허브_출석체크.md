# ✅ 깃허브 출석체크 — 내 학습 기록 남기기

> 이 과정의 출석체크는 종이에 사인하는 게 아니라, **매 수업마다 배운 내용을 내 깃허브(GitHub) 저장소에 기록(커밋)하는 것**으로 합니다.
> 깃허브는 커밋한 날마다 잔디(초록 칸)가 채워지기 때문에, 잔디밭이 곧 나의 출석부이자 포트폴리오가 됩니다. 🌱

## 왜 깃허브로 출석체크를 하나요?

1. **기록이 남는다** — 오늘 배운 명령어를 내일 잊어도, 내 저장소에 다 있습니다.
2. **잔디가 곧 출석부** — 프로필의 초록 잔디 칸 = 그날 공부했다는 증거. 선생님도 한눈에 확인할 수 있습니다.
3. **포트폴리오가 된다** — 과정이 끝나면 "젯슨나노로 AI 수료증 딴 과정 전체"가 담긴 저장소가 남습니다. (이 저장소도 그렇게 만들어진 것입니다!)

---

## 1단계. 깃허브 계정 만들기 (최초 1회)

1. 컴퓨터 브라우저에서 https://github.com 접속 → **Sign up**
2. 이메일 → 비밀번호 → 사용자이름(username, 영문) 입력
   - 💡 username은 나중에 포트폴리오 주소(`github.com/내이름`)가 되니 신중하게!
3. 이메일로 온 인증 코드 입력하면 가입 완료.

## 2단계. 출석체크용 저장소(Repository) 만들기 (최초 1회)

1. 로그인 후 오른쪽 위 **`+`** 버튼 → **New repository**
2. 아래처럼 입력:
   - **Repository name** : `jetson_DLI` (또는 원하는 이름)
   - **Public** 선택 (잔디가 보이려면 Public 권장)
   - ✅ **Add a README file** 체크 ← 꼭!
3. **Create repository** 클릭. 끝!

## 3단계. 마크다운(md) 작성법 5분 배우기

출석 기록은 **마크다운(.md)** 파일로 씁니다. 이것만 알면 됩니다:

```markdown
# 큰 제목          ← # 한 개
## 중간 제목       ← # 두 개

- 목록 항목 1      ← 하이픈(-)으로 목록
- 목록 항목 2

**굵은 글씨**      ← 별표 2개로 감싸기

`jtop`             ← 명령어는 백틱(`)으로 감싸기

​```
sudo apt-get update   ← 여러 줄 명령어는 백틱 3개로 감싸기
​```

![사진 설명](img/사진이름.png)   ← 이미지 넣기
```

> 💡 더 배우고 싶으면: https://docs.github.com/ko/get-started/writing-on-github

## 4단계. 매 수업 끝나기 전 — 출석 기록 남기기 (매번!)

가장 쉬운 방법은 **깃허브 웹사이트에서 직접** 쓰는 것입니다:

1. 내 저장소 페이지 접속 → **Add file** → **Create new file**
2. 파일 이름 입력: `day01_젯슨나노세팅.md` 처럼 날짜/주제를 넣어서
3. 아래 템플릿을 참고해 오늘 배운 내용 작성:

```markdown
# Day 1 — 젯슨나노 첫 부팅과 우분투 설치 (2026-07-27)

## 오늘 배운 것
- 젯슨나노에 SD카드 넣고 우분투 초기 설정 (계정 dli/dli)
- 터미널에서 `ifconfig`로 IP 주소 확인하는 법

## 오늘 쓴 명령어
​```
sudo apt-get update
sudo apt-get upgrade
​```

## 오늘의 스크린샷
(스크린샷을 여기에 드래그하면 자동으로 올라갑니다)

## 느낀 점 / 어려웠던 점
- 비밀번호 입력할 때 화면에 안 보여서 당황했는데 원래 그런 거였다!
```

4. 아래 **Commit changes** 버튼 클릭 → 초록 잔디 한 칸 완성! ✅

> 💡 스크린샷은 글 쓰는 칸에 **이미지 파일을 드래그**하면 자동으로 업로드됩니다.
> 💡 젯슨나노에서 스크린샷 찍는 법: 키보드의 `PrtScr` 키 (3단계 세팅 후 가능)

## 5단계. (선택) 젯슨나노 터미널에서 git으로 올리기

리눅스 명령어에 익숙해지면 터미널에서 직접 올려봅시다. 리눅스 공부도 됩니다:

```bash
# 최초 1회: 내 저장소 복제 + 이름/이메일 등록
git clone https://github.com/내아이디/jetson_DLI.git
cd jetson_DLI
git config --global user.name "내아이디"
git config --global user.email "가입한이메일"

# 매번: 파일 만들고 → 올리기
gedit day02_jtop과쿨링팬.md     # 파일 작성 후 저장
git add .
git commit -m "Day 2 출석: jtop 설치와 쿨링팬"
git push
```

> ⚠️ push 할 때 비밀번호는 깃허브 로그인 비밀번호가 아니라 **개인 액세스 토큰(PAT)**입니다.
> 깃허브 → Settings → Developer settings → **Personal access tokens** → Generate new token (repo 권한 체크)
> 발급된 토큰을 비밀번호 자리에 붙여넣으세요. (한 번 발급받으면 복사해서 보관!)

## 6단계. 출석 확인하기

- 내 프로필(`github.com/내아이디`)에 들어가면 **잔디밭(Contributions)**에 초록 칸이 채워집니다.
- 수업에 참여한 날 = 초록 칸. 과정이 끝나면 잔디밭 스크린샷도 기념으로 남겨두세요! 🌱🌱🌱
